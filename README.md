# Larp RNG

This is s1mple macro for Sol's RNG. It have features like Potion craft, Eden farm etc.
Every function were written by me (but Frontend mostly with AI).
I wish you enjoy it (also if you think macro stucked, dont worry it will fix it self by time)

## Technologies
* This macro written on AHK 1.1
* Uses RapidOCR, ImagePut 

## Usage
Open Larp RNG.ahk
Toggle switches: On means this function would be used on start, Off means this function disabled on start
Biome selector: On "Biomes" tab you can see bunch of biomes, choose if you would like to skip the biome or keep it so Biome Randomizer or Strange Controller wouldn't skip it
Lastly choose in settings your path methods
After you chose everything press F1 to start (or click start button), F2 will reload the macro 

## IMPORTANT!!!
Currently this macro supports only 1920x1080 resolution (maybe in future i will add callibrations so you can callibrate macro to your resolution).
If you using Display Port for your monitor, DONT turn off monitor when macro started(it will break RapidOCR so nothing will work). If you want to turn off monitor just use HDMI or HDMI+DP

# Rus.
Это простой макрос для игры Sol's RNG. В нем реализованы такие функции, как создание зелий (Potion craft), фарм Эдена (Eden farm) и другие.
Весь функционал написан мной (интерфейс — преимущественно с помощью ИИ).
Надеюсь, вам понравится! (Если покажется, что макрос застрял — не переживайте, через некоторое время он сам придет в норму).

## Технологии
* Макрос написан на языке AHK 1.1.
* Используются библиотеки RapidOCR и ImagePut.

## Использование
Откройте файл Larp RNG.ahk
Переключатели: положение «On» означает, что функция будет активна сразу после запуска, «Off» — функция отключена.
Выбор биомов: на вкладке «Biomes» представлен список биомов. Вы можете выбрать, какие из них нужно пропускать, а какие — оставить (чтобы «Biome Randomizer» или «Strange Controller» их не пропускали).
В настройках выберите предпочтительные способы перемещения (path methods).
После настройки всех параметров нажмите F1 (или кнопку «Start»), чтобы запустить макрос. Клавиша F2 перезагружает и останавливает макрос.


## ОЧЕНЬ ВАЖНО!!!
На данный момент макрос поддерживает только разрешение экрана 1920x1080 (возможно, в будущем я добавлю функцию калибровки под другие разрешения).
Если ваш монитор подключен через DisplayPort, НЕ выключайте его во время работы макроса (это приведет к сбою RapidOCR, из-за чего макрос перестанет работать). Если вам нужно выключить монитор, используйте подключение через HDMI (или комбинацию HDMI + DP).
